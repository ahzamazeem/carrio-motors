# 🎓 My First Semester Project | Web Development Foundation

Welcome to my very first semester project! 🚀 This website was built back when I was starting my journey in web development and learning the fundamentals of the web. It represents my early days of exploring code, layouts, and interactive elements.

👉 **[Live Demo Available Here](https://ahzamazeem.github.io/Gsap_Portfolio/)**

---

## 📝 Project Overview

The main objective of this project was to understand the building blocks of front-end development and apply structural and styling concepts. It features a clean, responsive layout designed using a mix of raw styles and a popular CSS utility framework.

### 🌟 Key Learning Milestones:
- **Semantic HTML:** Learning how to structure web pages correctly.
- **Custom CSS Styling:** Understanding layouts, colors, and typography.
- **Responsive Layouts:** Implementing a grid system to ensure the site looks good on both mobile and desktop screens.
- **Basic Interactivity:** Using JavaScript for foundational dynamic components.

---

## 🛠️ Tech Stack Used

- **HTML5:** For content and structure.
- **CSS3:** For custom styling, branding, and layout adjustments.
- **Bootstrap:** For fast, responsive grid systems and pre-styled components.
- **JavaScript (Vanilla):** For basic user interactivity and logic.

## 🚀 How to Run the Project Locally

If you want to view this project on your local machine:

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the folder:**
   ```bash
   cd Gsap_Portfolio
   ```
3. **Launch the project:**
   Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox).
